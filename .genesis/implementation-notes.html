Decisions that constrain new work

  • ADR-0001 — Postgres + pgvector is the single storage engine (no separate vector DB) → see decisions/0001-storage-engine-postgres-pgvector.md
  • ADR-0002 — selective admission: an LLM-judge Write Gate decides admit/reject/update before anything persists → see decisions/0002-selective-admission-write-gate.md
  • ADR-0003 — the Write Gate is async and queue-backed (Redis), never inline on the request path → see decisions/0003-write-gate-async-queue-backed.md
  • ADR-0004 — self-hosted single Docker Compose stack on a VPS; no managed cloud, so gates run inside the stack → see decisions/0004-self-hosted-docker-compose.md
  • ADR-0005 — hybrid retrieval (pgvector + tsvector + Postgres entity-link table); no Neo4j, no Elasticsearch in v1 → see decisions/0005-hybrid-retrieval.md
  • ADR-0006 — tenant isolation enforced by Postgres RLS on every memory-bearing table, not application filtering alone → see decisions/0006-tenant-isolation-via-rls.md
